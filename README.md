# The Funniest Toaster Error Message

Entry for make.fun competition
`u-eager-stork-81-9647-the-funniest-toaster-error-436406cd` ($2, winner takes all).

`main.ts` (Node 22, standard library only) holds a small bank of original
one-line toaster error messages, scores each on the judge's published
criteria, and writes the winner to `/output/entry.txt`.

Winning line (66 characters):

> Crumb tray full. I have been quietly eating your crumbs for weeks.

Run: `node main.ts` (or with `MAKEFUN_OUTPUT_DIR` set outside the grader).
Deterministic — two runs produce byte-identical output.
